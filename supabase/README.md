# Supabase setup

This folder will contain database setup files for the workflow templates.

## Planned tables

- `ig_accounts` - connected Instagram account metadata
- `kw_flows` - keyword to response mapping
- `dm_queue` - pending message queue
- `dm_logs` - delivery and event logs

## Security note

Keep private credentials outside public SQL examples. Store sensitive values only in your private Supabase project, private n8n credentials, or deployment environment.

## Current status

The production schema is being converted into a clean public example with placeholders and safe defaults.
