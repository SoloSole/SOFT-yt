# Contributing

Thanks for considering a contribution.

This project is focused on practical, documented n8n workflow templates for creators, marketers, indie builders, and small teams.

## Contribution ideas

- improve setup docs
- add troubleshooting notes
- add example workflows
- improve Supabase schema examples
- add screenshots or diagrams
- report broken workflow imports
- suggest safer defaults

## Rules for contributions

- Do not include real secrets or production credentials
- Do not include private domains, internal IPs, private account IDs, or personal emails
- Keep examples generic and reusable
- Explain what problem your workflow solves
- Include setup steps and known limits

## Workflow template standard

Each template should include:

- `workflow.json`
- `README.md`
- `setup.md`
- list of required services
- required environment variables
- testing steps
- known limitations

## Pull requests

Please keep pull requests small and focused. A good pull request should be easy to review and should clearly explain why the change is useful.
